A025 深色鬃毛：空间审计、载体对应修正与同风重测
日期：2026-10-21；未 push；未重训；未改变原始渲染资产。

结论
不是整片深色鬃毛都锁在根部。更主要的问题是：旧解码器选取“根附近的 Strand”，平移到 Shell 根后再求最近弧长，但这条曲线未必穿过该毛簇真正占据的空间。可见 Shell 大量依赖人工根部连接段及较大的局部偏移。只把绑定点往梢端推，或加大风力，都不能解决这个空间对应问题。
本次修正改善了截图区域的驱动对应和实际运动，但仍不是无穿插/无飞丝的物理就绪版本。全身深穿点及相邻簇差动风险略有增加，必须与运动改善同时报告。

一、原始空间分布与绑定审计
所有“截图区域占比”均以完整遮挡合成 Ti*alpha 可见贡献加权，不是拿裸 GS 数量冒充可见区域。颜色梯度求权重与 true-alpha / route 指示颜色渲染相互核验，误差约1e-7。
旧长 Shell 在该截图贡献全部 alpha 的74.13%；全部非 context Shell 为85.94%，实际 Strand 为11.11%。
旧绑定：
- 弧长比例中位数56.56%；落在前10%根段的权重9.74%，不是几乎全部绑在根部。
- 48.52%的绑定权重落在人工根部连接段上。
- 到驱动曲线的偏移中位数1.719%D；偏移/载体总长中位数25.81%。
- 有效载体长度中位数6.539%D；8.98%权重的载体长度小于根到 GS 中心的直线距离。
所以主要是曲线空间路径不匹配及连接段占比过大，局部有长度不足；不能简单概括为“所有载体都太短”。

截图 Shell 的静态空间检查：
- 身体外侧距离中位数3.472%D，长鬃毛离皮肤较远本身并不错误。
- 深入身体超过0.1%D的可见权重0.506%；全2sigma仍埋入身体的可见权重0.108%。
- 按自身尺度和全局间距定义的孤立点权重0.229%。最大sigma中位数0.520%D，仍存在较粗的聚合渲染单元。
- 原生 Catmull-Rom GT groom 的分层抽样包络：到采样毛发最近距离中位数0.268%D；超过自身2sigma加0.5%D余量的疑似远离权重4.38%。半量曲线采样时为7.95%，有明显抽样不确定性，不能当成完整 OTC 或精确全量 outlier 率。
- 全身非 context Shell 仍有1.56%数量满足全2sigma埋入身体、0.53%尺度相对孤立，不能宣称全部几何通过。
综合判断：这片可见鬃毛没有大面积孤立/深埋的证据，可以针对驱动对应做局部修正；全局资产仍有已有缺陷，不作全局物理合格认证。平行表面的切向不会被当成错误。

二、实际修改
复用原求解器、原生渲染器和检查流程，仅替换有几何支持的长 Shell 材料载体/对应关系，避免另造训练管线。
- 用冻结 Shell 毛簇自身的中心和 opacity 沿根距离构建连续物理导杆，并使用已知身体作初始离群/深穿检查；没有用 GT 毛发。
- 根位置保持不变；按固定弧长坐标和局部坐标系驱动 Shell 中心及完整各向异性协方差旋转。宽度、SH、opacity不变。
- 616条候选物理曲线中剔除36条初始深穿/连接路径不合格曲线，保留580条，9625节点/9045边。
- 最终11761个 Shell GS 得到通过几何匹配门限的新载体。该集合覆盖截图全部 alpha 的61.71%；未支持部分保留旧解码，不删除、不隐藏。
- 新曲线仅是物理载体，不新增可渲染 Strand/GS，也不改原有 Strand 图；短毛保持原层状滑动。
- 几何和离散方式变化会改变力臂/响应，不等于经材料标定的物理公平比较；没有提高风参数。

- 身体、实际 Strand 根、Shell物理载体根位移均0；原阵风实际 Strand /短毛在frame14与旧版逐值一致。

后续应在保留本次空间对应的基础上做相邻载体一致性和动态接触响应；不靠加大风力掩盖问题，也不把静态模糊归因于风力不足。
