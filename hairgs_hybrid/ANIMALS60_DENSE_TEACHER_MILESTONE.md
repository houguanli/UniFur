# Animals60 Dense-Teacher Compression Milestone

## Scope

This milestone evaluates the dense-teacher topology-compression pipeline on
eight Animals60 cases. Every method uses the same 48 fitted views, 12 held-out
views, 512x512 raster resolution, cameras, ground truth and evaluator.

The ratio experiments first fit an unrestricted HairGS scaffold, then construct
an exact-budget HairGS control and a neutral Shell/Fin/Strand candidate bank
from that frozen scaffold. Consequently, their reported optimization time is
incremental compression/refinement time and is not end-to-end training time.

At 75% compression, UniFur reduces mean deployment size from 118.90 MiB to
29.86 MiB and raises measured rendering throughput from 151.35 to 251.59 FPS.
Against the equal-budget HairGS control, it reduces false-positive area on all
eight cases and improves IoU on seven. It also loses 2.350 dB foreground PSNR
and increases false-negative area, so this version supports a structured,
overflow-resistant representation claim rather than superior rate-distortion.

## Full-image metric diagnosis

The evaluator distinguishes foreground PSNR, masked-full PSNR and full-image
PSNR. On unrestricted HairGS, 88.36% of pooled held-out full-image MSE lies
outside the ground-truth foreground mask. Low-opacity Gaussian tails over a
large black background therefore dominate the full-image number. UniFur's
higher full-image PSNR is an overflow benefit; it must not be presented as an
appearance-quality improvement without the masked metrics.

## Reproduction

```bash
bash hairgs_hybrid/run_animals60_all.sh
bash hairgs_hybrid/run_animals60_ratio_all.sh
```

The auditable summaries are generated by:

```bash
python hairgs_hybrid/audit_animals60_benchmark.py
python hairgs_hybrid/audit_animals60_ratio_ladder.py
```

Datasets, checkpoints and renders are deliberately kept outside Git.

## Next hypothesis

The learned route bank currently inherits geometry, soft-opacity tails and
appearance bias from the unrestricted dense teacher. The next experiment must
construct a budget-scaled scaffold directly from fitted observations, learn its
topology without reading dense-teacher weights, and compare it under the same
Horse protocol before replacing this milestone.
